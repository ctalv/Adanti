# Adanti 

## Premise
I was tired of all the ads on my smart TV. I had a spare PC lying around, so decided to use that for my TV (via HDMI). THIS DOES NOT PREVENT AD SCRAPING. It just ensures you are not instantly bombarded with advertisement the moment you turn your smart TV on.

This is just a simple homepage for naviagting streaming apps in a browser. And no data is hosted on a cloud server (for better or for worse).

## Software
- HTML
- JS
- CSS
- IndexedDB


## Goals
### Customization
- Edit the overall theme:
  - Dark/Light mode
  - Background image/color
  - Font, font color, and font size
- Show or hide preferred widgets
- Edit individual widget layout, alignment, size, etc.

### Widgets
So far, there is only a clock and apps widget. I plan to add:
- Search
- Weather
- News
- Quotes

### TV 
- Usage with a remote

### IndexedDB
- Export/backup and import all database data
- Store user preferences
- Solution for cleared cache issue
